# Сверка iOS с Aerial для ТВ (`F:\Aerial`)

Сверено 24 октября 2026 по `VodScreen.kt` (страница фильма), `VodCinemaSettings.kt` и `SettingsScreen.kt` (настройки),
`ReleaseSheet.kt` (фильтры раздач), `Ratings.kt`, `VodPalette.kt`, `TorrentState.kt`.

## Перенесено в этой сверке

| ТВ | iOS |
|---|---|
| Порядок разделов страницы фильма: актёры, серии, отзывы, «Интересные факты», франшиза, похожие, «Духовные родственники», «Ещё от студии» | `DetailsView.sections` — тот же порядок; отзывы и факты раньше стояли в самом низу, их не находили |
| «Интересные факты» видны всегда («Загружаем…» / «недоступна в Wikipedia») | `WikiStorySection` |
| «Ещё от студии …» и капсулы студий рядом с жанрами (`GenreChips`) | `VodDetails.studios/studioFilms`, капсулы жанров и студий под строкой сведений |
| Оценки строкой: знак источника и кольцо (`RatingsRow`) | `RatingsRow` в `UI/Palette.swift` |
| «Показывать оценки MDBList» и выбор источников (IMDb, Rotten Tomatoes, Metacritic, Letterboxd) | «Настройки › Каталог и оценки» |
| Цвет постера (`VodPalette`) на кнопках | `PosterPalette`: кнопки страницы фильма и плеер |
| «Описания серий», «Скрывать спойлеры серий» | «Настройки › Плеер › Серии» |
| «Очистить «Продолжить»», «Очистить историю просмотра», «Начать рекомендации с нуля» | «Настройки › Рекомендации» |
| «Очистить историю поиска», «Сбросить фильтры и сортировку раздач» | «Настройки › Плеер» |
| Фильтры раздач (перевод, трекер, HDR, Dolby Vision, субтитры) | кнопка фильтра на странице раздач |
| Окно файлов раздачи перед просмотром | `WatchSheet`: озвучка, сезон, серия / файл |
| «Торренты» и «Добавить торрент» | «Медиатека › Торренты» (`TorrentsView`): список TorrServer, добавить по ссылке, удалить |
| «История» | ряд «История» в Медиатеке |

Вторым проходом:

| ТВ | iOS |
|---|---|
| Фильтры «Язык», «Сезон», «Год», «3D», сортировка «Просмотренные» | `ReleaseFacts` (перенос `ReleaseFacts` ТВ), меню фильтров раздач |
| Встроенный трейлер (`VodTrailer`) | `TrailerView`: плеер YouTube внутри приложения |
| «Размер постеров», «Размер фото актёров», «Логотипы названий» | «Настройки › Вид» |

Сверх ТВ: «Картинка в картинке» (`PictureInPicture`, для MP4/MOV/M4V — их понимает AVPlayer; MKV через системное окно
не сыграть) и загрузки в Dynamic Island (`DownloadLive`, виджет `AerialWidgets`).

## Не переносится — особенности ТВ и Windows

Обновления из GitHub Releases, мастер первого запуска, автозапуск, внешние плееры, туннельный режим, тестовые рычаги
вида («стекло», «колода», «смена кадров», «сведения на постере»). PIN-замка в Aerial нет.
